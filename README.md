# OppPilot

A prototype that finds, checks and prepares every opportunity a student qualifies for, before the deadline.

**Team Code Crusaders** (IGDTUW): Esha Kumar, Khushi Srivastava
**Event:** HackIIITD Finals, Oct 24-25, 2026
**TinyFish APIs used:** Search, Fetch, Web Agent

## Note on commit history
The earliest commits are Lovable's default project starter template (TanStack Start), created when a new Lovable project is initialised. It contains no OppPilot logic. All OppPilot features, UI and TinyFish integration were built during the hackathon, as the commits since show.

## Stack
Lovable (React + TypeScript), Lovable Cloud (database, auth, edge functions), TinyFish Search / Fetch / Agent APIs. The production architecture in our Round 1 deck (Next.js, FastAPI, Redis) is the scale-up plan.
