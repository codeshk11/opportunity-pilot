# OppPilot
A prototype website that helps college students find, verify and prepare for opportunities they qualify for, before the deadline. Built with TinyFish API integration.

# Problem
College students in India have no single, trustworthy, personalised place to discover scholarships, internships, hackathons and schemes. Listings are scattered, unverified and repetitive to apply for.

# What the prototype does
- Takes a student profile
- Finds opportunities from the live web using TinyFish
- Shows deadline and eligibility on one card with its source link
- Matches opportunities to the student's profile

# Note on commit history
The earliest commits are Lovable's default project starter template(TanStack Start),created when a new Lovable project is initialised.It contains no OppPilot logic.All OppPilot features,UI and TinyFish integration were built during the hackathon, as the commits since show.


# Tech Used
Lovable (React+TypeScript),Lovable Cloud(database,auth,edge functions),TinyFish Search / Fetch / Agent APIs.The production architecture in our Round 1 deck (Next.js, FastAPI, Redis) is the scale-up plan.
