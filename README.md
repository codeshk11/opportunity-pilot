# Opportunity Pilot

Create "OppPilot", an AI agent web app that helps Indian college students find, verify and prepare applications for scholarships, internships, hackathons and government schemes.

Design system (use everywhere):

- Soft pastel theme: background cream #FBF8F3, cards in pastel mint #D9F2E6, lavender #E6E0F8, peach #FFE3D3, sky blue #D6EAF8, butter yellow #FFF4C2. Dark text #2B2B3A, primary accent soft purple #8B7CF6.

- Rounded-2xl cards, soft shadows, DM Sans font.

- Bento grid layout: uneven card sizes in a responsive grid.

- Hover animations: cards lift (translateY -4px) with a stronger shadow, buttons scale slightly, smooth 200ms transitions, subtle fade-in on page load.

Build only the landing page for now: a hero ("An AI agent that finds, checks and prepares every opportunity you qualify for, before the deadline") with a "Get started" button, and a bento grid of 5 feature cards: Discover, Verify, Match, Prep & Remind, and "You always press submit". Fully responsive.
